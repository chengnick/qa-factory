# REQ-001 使用者識別與專案成員

每個 API 請求以 `X-User: <username>` header 識別使用者。系統預設使用者：`alice`、`bob`、`carol`、`dave`。

## 驗收準則
- 缺少 `X-User` 或使用者不存在 → `401`。
- `POST /api/projects` 建立專案，建立者自動成為該專案的 `owner` 成員。
- 只有專案 owner 可透過 `POST /api/projects/{pid}/members` 加入成員；非 owner → `403`。
- 加入不存在的使用者 → `422`；重複加入 → `409`。
- `GET /api/projects` 只列出自己參與的專案。
