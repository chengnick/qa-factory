# TaskBoard API reference

Reference given to the test-design and automation agents, the way a QA engineer would get API docs.
It describes the interface only; expected behaviour comes from the requirement documents.

## Identity

Every `/api/*` request identifies the caller with the header `X-User: <username>`.
Seeded users: `alice`, `bob`, `carol`, `dave`. Missing or unknown user → `401`.

## Resources

**Project**: `{id, name, owner_id}`. The creator becomes owner and member.
**Task**: `{id, project_id, title, description, status, priority, assignee_id, created_by, created_at, updated_at}`.
`status` ∈ `todo | in_progress | done` (new tasks start as `todo`); `priority` defaults to 3.

Errors are JSON `{"detail": ...}`. Validation errors use `422`.

## Endpoints

| Method | Path | Body / query | Success |
|---|---|---|---|
| GET | `/health` | | `200 {"status":"ok"}` |
| GET | `/api/users` | | `200 [{id, username}]` |
| POST | `/api/projects` | `{name}` | `201` project |
| GET | `/api/projects` | | `200 [project]`: projects the caller belongs to |
| GET | `/api/projects/{pid}` | | `200` project + `members: [{id, username, role}]` |
| POST | `/api/projects/{pid}/members` | `{user_id}` | `201 {project_id, user_id, role}` |
| GET | `/api/projects/{pid}/tasks` | query: `status`, `q`, `limit`, `offset` | `200 {items: [task], total, limit, offset}`, ordered by id |
| POST | `/api/projects/{pid}/tasks` | `{title, description?, priority?}` | `201` task |
| GET | `/api/tasks/{tid}` | | `200` task |
| PATCH | `/api/tasks/{tid}` | any of `{title, description, priority, assignee_id}` | `200` task |
| POST | `/api/tasks/{tid}/transition` | `{to: "<status>"}` | `200` task |
| DELETE | `/api/tasks/{tid}` | | `204` |

## Web UI

`GET /` serves a single-page board. Query `?user=<username>&project=<pid>` preselects user and project.
The page sets `data-ready="true"` on `<body>` once its initial load has finished.

| Element | `data-testid` |
|---|---|
| user select | `user-select` |
| project select | `project-select` |
| new-task title input | `new-title` |
| create-task button | `create-btn` |
| error message area | `error` |
| task list (`<ul>`) | `task-list` |
| one task row (`<li>`) | `task-item` |
| task title inside a row | `task-title` |
| task status inside a row | `task-status` |
| "advance status" button inside a row | `advance-btn` |
